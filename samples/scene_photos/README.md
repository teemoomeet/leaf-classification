# scene_photos — 真实场景照片示例

用于演示 `predict --whiten auto`（白底对齐）在**非白底扫描图**的真实拍摄
条件下的表现，以及系统的不确定性报告机制。

| 文件 | 内容 | 肉眼参考 |
| --- | --- | --- |
| `scene_00_心形叶.jpg` | 黄绿色心形叶（绿色植被背景） | 紫荆（Cercis chinensis） |
| `scene_01_竹叶簇.jpg` | 暗背景下的竹叶簇，带水珠 | 毛竹（Phyllostachys edulis，Flavia 中唯一竹类） |
| `scene_02_白底双叶.jpg` | 白底两片革质椭圆叶 | 日本珊瑚树 / 柑橘（外形相近） |
| `scene_03_轮生枝叶.jpg` | 绿色灌丛中的轮生枝条 | 日本珊瑚树 / 柑橘 / 桂花（外形相近） |

## 快速复现

```bash
python -m leaves.cli predict --input samples/scene_photos --model models/flavia_ft_mobilenetv3.pt
```

## 结果怎么读（重要）

这批照片**故意选了困难样本**：多叶簇生、暗色/植被背景、水珠反光。
实测表明（详见主 README 的「真实场景照片」一节）：

- 白底单片叶是本项目的可靠区间（Flavia 测试集 97.9%~99.2%）；
- 复杂场景照上各模型均会出错，但系统会通过 **低置信度提示**
  （`low_confidence` 列 / `⚠` 标记）明确报告不确定，请以 top-3 候选
  与人工复核为准；
- 要在您的场景获得可靠结果：优先拍摄「白底 + 单片叶 + 叶面摆平」，
  或用 `match` 命令自建参考图库。
